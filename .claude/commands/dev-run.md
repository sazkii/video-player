# 全自动项目开发

你将按照 PROJECT.md 的完整定义，自动执行 7 阶段开发流水线。全程不停顿，遇到问题自动调试解决。

## 执行规则

1. 先读取 PROJECT.md 了解完整需求
2. 按 7 个阶段顺序执行，每阶段完成后简要报告进度
3. 不主动询问用户，遇到问题自主决策
4. 每阶段输出关键文档到项目根目录
5. 最终生成 REPORT.md 汇总

## 阶段 1: 产品经理

读取 PROJECT.md，输出 `PRD.md`：
- 产品定位与用户画像
- 功能优先级矩阵（P0/P1/P2）
- 用户故事
- 验收标准
- MVP 范围确认

## 阶段 2: 架构师

基于 PRD.md，输出：
- `system_design.md` — 技术架构与组件关系
- `data_model.md` — 状态管理设计（React state）
- `api_design.md` — 模块接口定义（Hook API）

必须包含：
- 组件树图（Mermaid）
- 状态流转图
- 关键 Hook 的输入输出定义

## 阶段 3: 工程师

**严格 TDD 流程：先写测试，再写实现**

按优先级 P0 → P1 → P2 顺序开发：
1. 初始化项目（Vite + React + TS + Tailwind）
2. 搭建基础组件骨架（空壳 + Props 类型）
3. 为每个组件写测试用例
4. 实现功能使测试通过
5. 确保所有测试通过后继续下一个

关键组件清单（按开发顺序）：
1. 类型定义 (`types/video.ts`)
2. 工具函数 (`utils/formatTime.ts`)
3. 自定义 Hook (`hooks/useVideoPlayer.ts`)
4. VideoPlayer 组件
5. Controls 组件
6. InputArea 组件
7. Playlist 组件
8. App 组件整合

## 阶段 4: 代码审查

执行 `/code-review` 对整个项目进行审查：
- 检查代码质量、TypeScript 类型安全
- 检查组件拆分是否合理
- 检查是否有未处理的边界情况
- 修复发现的问题

执行 `/simplify` 进行简化优化：
- 消除重复代码
- 优化组件性能（不必要的重渲染）
- 简化复杂逻辑

## 阶段 5: 测试工程师

完善测试覆盖：
- 单元测试: 工具函数 + Hooks
- 组件测试: 用户交互流程
- 确保 `npm test` 全部通过

## 阶段 6: 安全审计

检查并修复：
- XSS 防护（URL 输入验证）
- 文件类型验证（拖拽上传）
- 无敏感信息泄露
- 依赖安全性检查

## 阶段 7: 交付

1. 运行 `npm run build` 确保构建成功
2. 生成 `REPORT.md`，包含：
   - 项目概览
   - 已完成功能清单
   - 技术架构图
   - 运行说明
   - 已知问题
3. Git 初始化并提交

---

开始执行：先读取 PROJECT.md，然后从阶段 1 开始。
